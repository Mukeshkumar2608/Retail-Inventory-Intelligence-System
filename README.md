# Retail Inventory Intelligence System

An end-to-end retail analytics and business intelligence project built using
Python, MySQL, and Power BI to analyze sales performance, inventory health,
customer behavior, store performance, and promotion effectiveness.

## Project Overview

This project transforms raw retail data into actionable business insights
through data cleaning, data quality assessment, feature engineering,
advanced SQL analytics, and interactive Power BI dashboards.

## Tech Stack

- Excel
- Python
- Pandas
- MySQL
- Power BI
- DAX

## Dataset

The project integrates six business datasets:

- Sales
- Products
- Customers
- Stores
- Inventory
- Promotions

## Project Workflow

Raw Data
→ Data Cleaning
→ Data Quality Assessment
→ Feature Engineering
→ Exploratory Data Analysis
→ Advanced SQL Analysis
→ Power BI Dashboard
→ Business Insights
